# Rashid

كيف تنتبه لتسرّب المياه قبل ما يبان أثره في الفاتورة؟ من هنا بدأت فكرة رشيد. طوّرت التطبيق لمتابعة استهلاك المياه والتنبيه عند رصد نمط غير معتاد قد يشير إلى تسرّب. وفي النموذج الأولي، تقدر تشغّل محاكاة تسرّب وتشوف كيف تتغيّر القراءات ومتى يظهر التنبيه.

محمد سعد الأحمري
صاحب فكرة رشيد ومطوّره. تولّيت المشروع من الفكرة إلى بناء النموذج الأولي، بما فيه تصميم الواجهات وبرمجة التطبيق ومنطق المحاكاة والتنبيهات
